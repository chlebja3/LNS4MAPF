auto Visualizer::generate_random_color ( int  mix_r,
int  mix_g,
int  mix_b,
double  mix_ratio = 0.5 
) -> sf::Color
private

Generate a random color. To make the color palette look more visually pleasing, the random color is mixed with (mix_r, mix_g, mix_b).

Parameters
mix_rThe red channel value of the mix color, recommended value is 255.
mix_gThe green channel value of the mix color, recommended value is 255.
mix_bThe blue channel value of the mix color, recommended value is 255.
mix_ratioThe ratio at which to blend the randomly generated color with the mix color.
Returns
A random color.
